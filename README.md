# 마크 자동 낚시 — 화면 자막 인식

Windows 10/11용 프로그램입니다. 게임의 오른쪽 아래 자막 영역을 캡처하고, Windows 내장 한국어 OCR로 **“낚시찌가 첨벙거림”**을 감지하면 우클릭으로 회수한 뒤 다시 던집니다. 화면 인식과 OCR은 PC 안에서 처리됩니다.

## 실행

GitHub에서는 **Code → Download ZIP**으로 내려받아 압축을 해제하거나 `git clone https://github.com/SJW1212/autoFishing.git`으로 복제하세요. 실행에 필요한 배포본은 `release/MinecraftSubtitleFisher/`에 포함되어 있습니다.

이 폴더의 **`실행.cmd`를 더블클릭**하세요. 또는 `release/MinecraftSubtitleFisher/MinecraftSubtitleFisher.exe`를 실행하세요. Python을 별도로 설치할 필요는 없습니다. 실행 파일 옆의 `_internal` 폴더도 필요하므로 실행 파일만 따로 옮기지 마세요.

1. 마인크래프트 Java Edition에서 **설정 → 접근성 설정 → 자막 표시**를 켭니다. 한국어로 설정하세요.
2. 물가에서 낚싯대를 들고 게임 화면을 활성화합니다.
3. **F6**을 누르고 오른쪽 아래 **자막 전체가 표시되는 영역**을 드래그합니다. 줄이 늘거나 순서가 바뀔 수 있으므로 한 줄만 선택하지 마세요. 게임 창은 자동 등록됩니다.
4. 게임으로 돌아가 수동 낚시를 한 번 해 보세요. 프로그램으로 돌아오면 최근 인식한 글과 자막 영역 미리보기를 확인할 수 있습니다. 이 단계에서는 클릭하지 않습니다.
5. 찌를 회수해 둔 상태로 게임에서 **F8**을 누릅니다. 약 0.6초 후 첫 투척을 하고 입질 자막을 기다립니다.
6. 중지하려면 **F9**를 누릅니다. **F8**도 시작/중지를 전환합니다.

찌를 이미 던졌다면 시작 전에 **“이미 찌를 던져 둠”**을 체크하세요. 이 옵션은 프로그램을 다시 켤 때 항상 해제됩니다. 창에서 “3초 후 시작”을 누를 수도 있습니다. 3초 안에 게임으로 돌아가세요.

## 단축키

| 키 | 동작 |
|---|---|
| F6 | 현재 게임 창 등록 후 자막 영역 선택 |
| F7 | 게임 창 등록 / 저장된 영역으로 인식 재연결 |
| F8 | 자동 낚시 시작 또는 중지 |
| F9 | 즉시 중지 / 예약 시작 취소 |
| Esc | 영역 선택 취소 |

## 감지와 중복 방지

- 기본 문구는 `낚시찌가 첨벙거림`입니다. 이 PC의 `.minecraft/assets/indexes/36.json`에 연결된 한국어 번역 파일에서 확인했습니다.
- `무언가가 튀는 소리`, `낚시찌를 던짐`, `낚시찌를 회수함`은 기본 입질 문구와 다릅니다.
- 다른 버전이나 리소스팩에서는 **실제로 화면에 표시되는 입질 자막 문구**로 설정을 바꾸세요. `첨벙`처럼 너무 짧은 공통 단어보다 전체 문구를 권장합니다.
- 공백과 화살표를 무시하고, 8글자 이상 문구는 한 글자 OCR 오독을 허용합니다. 기본 문구에 한해 실제 Unifont 검사에서 관찰한 `낚시찌가 침범거림` / `낚시찌가 점범거림`도 입질로 취급합니다.
- 투척 직후 기본 2.5초 동안 입질 입력을 무시합니다. **기존 입질 문구가 연속 0.4초 이상 보이지 않은 뒤 다시 나타나야** 회수합니다. 남아 있는 같은 자막으로 재클릭하지 않기 위한 처리입니다.
- 회수 후 기본 0.8초 뒤 재투척합니다. 기본 65초 동안 입질이 없으면 상태를 확인하도록 중지합니다. 시간 초과 때 임의로 클릭하지 않습니다.
- 횟수는 **회수 입력 횟수**입니다. 실제 잡힌 물고기를 확인하는 기능은 아닙니다.

## 실행 조건과 문제 해결

- 자막 기능이 있는 **Java Edition**을 기준으로 합니다. Bedrock Edition에서 같은 자막 기능이 제공된다고 가정하지 않습니다.
- 게임 창이 가려지거나 최소화되면 화면을 읽을 수 없습니다. 창 모드 또는 테두리 없는 전체 화면을 사용하세요. 게임 창을 벗어나면 자동 중지하며 자동 재개하지 않습니다.
- 채팅·인벤토리·메뉴를 열기 전 F9로 중지하세요. 같은 게임 창 안에서 열린 메뉴까지 자동으로 구분하지 않습니다.
- 창 이동은 추적하지만, 창 크기·화면 해상도·GUI 배율·글꼴이 바뀌면 F6으로 다시 선택하세요.
- 자막이 여러 줄이어도 문구 전체가 영역 안에 들어가야 합니다. 영역을 너무 크게 잡으면 주변 화면의 글까지 읽을 수 있습니다.
- 인식 결과가 비거나 잘못되면 자막 크기를 키우고 영역을 좁혀 다시 확인하세요. 지원하지 않는 리소스팩 글꼴은 인식 품질이 달라질 수 있습니다.
- 이 PC에서는 Windows 한국어 OCR을 확인했습니다. 다른 PC에서 한국어 OCR이 없다는 메시지가 나오면 **Windows 설정 → 시간 및 언어 → 한국어 → 언어 옵션 → 광학 문자 인식**을 설치하세요.
- 단축키 등록 오류가 나오면 중복 실행된 프로그램이나 F6~F9를 점유한 다른 프로그램을 닫으세요.
- 다른 자동 클릭·낚시 매크로와 동시에 실행하면 우클릭 입력이 겹칠 수 있으므로 하나만 실행하세요.
- 우클릭 입력이 막히면 게임과 프로그램의 실행 권한을 맞추세요. 기본 실행에는 관리자 권한을 요구하지 않습니다.
- 설정은 실행 파일 옆 `settings.json`, 예외는 `error.log`에 저장됩니다. 화면 이미지나 OCR 결과를 평소에 파일로 기록하지 않습니다.

## 검증 범위

`검증결과.md`를 참조하세요. 회귀 테스트, 합성 자막 OCR, 설치된 마인크래프트 글꼴 렌더링 OCR, Windows 화면 캡처, GUI 및 패키징을 확인합니다. 실제 게임 플레이와 물고기 획득은 별도 검증 대상입니다.

## 소스에서 실행 / 재빌드

```powershell
.\.venv\Scripts\python.exe app.py
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

`app.py`: 설정 화면 / 단축키 연결, `screen_ocr.py`: 화면 캡처 / OCR, `automation.py`: 문구 판정 / 낚시 상태 관리, `windows_io.py`: 게임 창 확인 / 우클릭 입력.

다음 진단 명령은 실제 게임에 마우스 입력을 보내지 않습니다. `--diagnose`는 합성 자막 검사 결과를 `diagnostics.json`에, `--smoke-test`는 GUI 검사 결과와 자기 창 이미지를 `ui_smoke.json` / `ui_smoke.png`에 저장하고 종료합니다.

```powershell
.\release\MinecraftSubtitleFisher\MinecraftSubtitleFisher.exe --diagnose
.\release\MinecraftSubtitleFisher\MinecraftSubtitleFisher.exe --smoke-test
```

인터넷 유사 구현 조사와 채택한 방식의 근거는 `자막감지_방식조사.md`에 있습니다.
