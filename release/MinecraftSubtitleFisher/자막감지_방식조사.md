# 마인크래프트 낚시 자막 감지 방식 조사

조사일: 2026-10-20. 아래 내용은 원저자 README 또는 공개 소스에서 확인했습니다. 소개된 과거 프로그램을 현재 게임 버전에서 직접 실행 검증한 것은 아닙니다.

## 같은 원리를 사용하는 공개 프로그램

| 구현 | 확인한 방식 | 이 프로젝트에 주는 의미 |
|---|---|---|
| [McFishy](https://github.com/xechor/McFishy) | AutoHotkey + Capture2Text. 사용자가 자막 영역을 드래그하면 OCR 결과 파일에서 `Fish`를 찾고 우클릭 회수·재투척. 저자는 Java 1.16.2 대상으로 작성, 1.16.5 동작 확인을 명시함. | 사용자가 말한 **화면 자막 OCR 방식이 실제로 사용됨**. 영역을 작게 잡되 자막 줄 이동을 포함해야 함. |
| [mc-autofisher 공개 소스](https://minecraftautofisher.readthedocs.io/en/latest/_modules/mc_autofisher/fisher.html) | 화면 일부 캡처 → Tesseract OCR → 문구의 편집 거리 비교 → 우클릭. 소스의 기본 비교 문자열은 `Fishing Bobber`. | OCR 오독 허용이 필요함. 다만 이 프로젝트는 투척·회수와 혼동하지 않도록 입질 전체 문구를 기준으로 함. |
| [alissone의 Python 낚시 스크립트](https://gist.github.com/alissone/a964214ae71109cc2e9ccc821b0985d5) | `mss`로 자막 영역 캡처 → OpenCV `matchTemplate`으로 입질 자막 이미지 비교 → 회수·재투척. | 문자를 읽지 않고 **자막의 글자 모양**을 비교하는 방법도 가능. 기준 이미지를 현재 언어·GUI 배율·해상도에 맞춰 직접 준비해야 함. |

위 사례의 대기 시간과 현재 버전 호환성을 그대로 채택하지 않았습니다. 코드나 실행 파일도 내려받아 실행하지 않았습니다. 원리를 확인하고 이 폴더의 구현을 새로 작성했습니다.

## 한국어 자막의 정확한 구분

이 PC의 `%APPDATA%/.minecraft/assets/indexes/36.json`과 연결된 `minecraft/lang/ko_kr.json`을 읽어 다음 값을 확인했습니다. 연결된 객체 해시는 `10dd563534860e65b71a510272202fe03dbd00f5`입니다. 이 번역을 모든 버전·리소스팩에 일반화하지 않습니다.

| 게임 이벤트 키 | 이 PC의 한국어 문구 | 기본 입질 판정 |

## 채택한 방식

**자막 영역만 캡처 → Windows 내장 한국어 OCR → 입질 문구 전체 비교 → 우클릭 회수 → 대기 후 재투척**을 사용했습니다.

이미지 비교 방식은 글꼴이 고정되면 유리하지만 기준 이미지를 사용자가 별도로 만들어야 합니다. 이 프로젝트는 문구를 바로 입력할 수 있는 OCR을 기본으로 골랐습니다. 이 PC에는 한국어 OCR이 설치되어 있으며, 별도 Tesseract 실행 파일이나 클라우드 OCR 없이 사용할 수 있습니다. Windows OCR은 설치된 인식 언어로 엔진을 만들고 이미지의 글을 반환합니다. ([Microsoft OcrEngine 문서](https://learn.microsoft.com/en-us/uwp/api/windows.media.ocr.ocrengine), [언어별 엔진 생성](https://learn.microsoft.com/en-us/uwp/api/windows.media.ocr.ocrengine.trycreatefromlanguage))

중요한 처리 사항은 다음과 같습니다.

1. **문구 구분:** `낚시찌`나 `첨벙`만 찾지 않고 전체 입질 문구를 비교합니다.
2. **OCR 오독:** 공백·화살표 제거, 긴 문구 한 글자 오류 허용, 설치된 마인크래프트 Unifont 검사에서 실제 관찰한 두 가지 전체 문구 오독 보정을 적용합니다. 임의의 두 글자 오류를 모두 허용하지 않습니다.
3. **자막 잔류:** 같은 자막이 남아 있는 동안 중복 클릭하지 않습니다. 최소 0.4초 동안 입질 문구가 사라진 것을 새 프레임들에서 확인한 뒤 재등장에 반응합니다.
4. **게임 상태:** 창 전환·화면 인식 지연 때 중지합니다. 게임 창 이동은 추적하고 크기가 달라지면 영역 재설정을 요구합니다.
5. **검증 한계:** OCR이 입질 문구를 읽었다는 사실과 실제 물고기를 잡았다는 사실은 다릅니다. 현재 검증은 `검증결과.md`에 기록합니다.

리소스팩이나 버전에 따라 실제 자막이 다르면 화면의 입질 문구를 직접 확인해 설정에서 바꾸면 됩니다.
