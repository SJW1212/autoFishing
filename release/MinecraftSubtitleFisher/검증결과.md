| 설치된 마인크래프트 Unifont 글꼴 검사 | PASS — 12개 | 4종 문구 × 3개 글자 크기를 메모리에서 렌더링해 OCR. 입질 문구만 일치. 실제 게임 스크린샷 검사와 다름 |
| 화면 캡처 → 작업 스레드 → OCR | PASS | 직접 만든 시험용 자막 창을 화면에서 캡처하고 입질로 판정. 관찰된 OCR 시간 59ms |
| 전역 단축키 | PASS | F6~F9 등록, 별도 메시지 스레드에 보낸 시험용 WM_HOTKEY 전달, 해제. 실제 사용자의 키 누름과 게임 포커스를 결합한 검사는 별도 |

| 실제 마인크래프트 낚시 및 아이템 획득 | NOT_RUN | 검사 시 게임 플레이를 실행하지 않음. 서버 지연·모드·리소스팩·다양한 화면 배경·장시간 연속 사용 미검증 |

## 증거 파일

- `diagnostics.json`: 소스 진단 결과.
- `minecraft_font_ocr.json`: 설치된 게임 글꼴 12개 검사 결과.
- `windows_integration.json`: 실제 화면 캡처와 작업 스레드 OCR 결과 및 실제 입력 생략 이유.
- `ui_smoke.png`: 소스 프로그램 UI 이미지.
- `release/MinecraftSubtitleFisher/diagnostics.json`: 패키징된 실행 파일 OCR·화면 캡처·단축키 진단.
- `release/MinecraftSubtitleFisher/ui_smoke.json`: 패키징된 실행 파일 GUI 검사.

이 결과는 프로그램 생성과 제한된 기능 검증의 기록입니다. 실제 물고기 획득이나 모든 게임 버전의 호환성을 검증했다고 의미하지 않습니다. 첫 사용 시 README의 수동 자막 인식 확인부터 진행하세요.
